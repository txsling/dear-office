# *Dear Office*
*Dear Office* is a short interactive fiction game implemented in Power BI. It should take around 20 minutes to complete. 

## How to run the game
To play *Dear Office*, install the Power BI Desktop app from the Microsoft Store (or equivalent for your system). 

Link to Microsoft's Power BI site: https://www.microsoft.com/en-us/microsoft-fabric/features/power-bi

## How to play
Click the Start button on the Title Page tab to begin the game. If you're playing in Power BI Desktop, you may need to Ctrl-click the button. (You can use standard clicks if you first publish the Power BI report to an instance of the Power BI service and open it there.)

On most of the report pages in the game, there will be a row of page navigation buttons at the top of the page, a HTML text box on the left side, and a list of action buttons on the right side. Use the page navigation at the top to move between different pages, representing different locations and time periods within the game. Click the buttons on the right to take actions within the game that may affect the story, which is presented in the text box. 

The game is complete when you have reached the end page. There is one optimal ending and four less optimal endings.
